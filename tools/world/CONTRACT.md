# Sideways GP open world: shared rules for every work group

The game is a static website (Vercel) at `/home/user/sideways-gp` (site root). It is plain browser JavaScript, no build
step for game code. `index.html` holds the existing game (menus, race engine, garage); the open world is being added as
separate script files next to it. **Only the orchestrator edits `index.html`, commits or pushes.** Each group owns the
files and folders listed in its brief and touches nothing else. Never publish Claude artifacts.

## Colour, units, coordinates
- Linear workflow: colour textures must be `texture.colorSpace = THREE.SRGBColorSpace`; normal/roughness maps stay
  linear. The game renders to a half-float target and its last pass does exposure, tone mapping (Khronos PBR Neutral)
  and the sRGB conversion, so materials must not tone-map themselves. Lights use physical units.
- 1 unit = 1 metre. Y up. **North is -Z, east is +X.** The world is **16000 x 16000 m** centred on the origin
  (x and z from -8000 to 8000). Sea level is y = 0 (the sea runs along the south and east edges).
  (A first 8 x 8 km draft exists; the world group is replacing it with the 16 km world in format v2 below.)
- Licences: only CC0 or MIT (or similar permissive) material. Write every source and its licence into a
  `CREDITS.md` in your output folder.

## World data, format v2 (generated by `tools/world/build_world.py`)
All numbers come from `world/world.json` (`N`, `size`, `hmin`, `hscale`); never hard-code them.
- `world/height.png`: RGB 8-bit PNG, N x N (N = 2048). Height value = R * 256 + G (B unused);
  metres = value / hscale + hmin (hmin = -100, hscale = 32, so -100 .. 1948 m). Row = z from north (-8000) to south
  (+8000), column = x from west to east, grid spacing = size / (N - 1). Sample bilinearly. In the browser decode it with
  `createImageBitmap(blob, {colorSpaceConversion: 'none', premultiplyAlpha: 'none'})` and a canvas, so bytes stay exact.
- `world/map.png`: RGBA N x N, same layout. R = distance to the nearest road edge in metres x 4 (capped at 255, i.e.
  63.75 m; 0 = on a road), G = forest density, B = desert, A = cherry-blossom (sakura) density, each 0..255.
- `world/world.json`:
  `{v:2, N, size, hmin, hscale, sea:0,
    roads:[{id, type, name, closed, hw, pts:[[x,y,z],...]}],
    towns:[{id, name, kind:'city'|'town'|'village', x, z, r}],
    buildings:{fields:['x','z','w','d','h','rot','y','style'], rows:[[...],...]},
    water:[{kind:'lake'|'river', level, pts:[[x,z],...]}],
    places:{spawn:{x,z,h}, festival:{x,z,r,name}, garage:{x,z,h,name}, castle:{x,z,y}, regions:[{id,name,x,z}]},
    pois:[{type:'speedtrap'|'driftzone'|'jump'|'view', x, z, h, len, road}],
    races:[{id, name, kind:'circuit'|'sprint'|'dirt'|'street'|'drag', laps, route:[[x,y,z],...], start:{x,z,h}}]}`
  Road `pts` are centre-line points about 8 m apart with the road surface height; `hw` is the half width; types:
  `hwy` (9 m half width), `road` (5.5), `street` (6, town grids), `dirt` (4.5), `track` (7, racing circuit).
  Headings `h` are radians, 0 = facing +Z (south), increasing towards +X.
- Shared PBR textures (Poly Haven, CC0, 1024 px WebP) in `world/tex/`: `<name>_diff.webp`, `<name>_nrm.webp`
  (OpenGL normal), some `<name>_rough.webp`. Names: grass, forest, rock, sand, desert, snow, gravel, asphalt, track,
  stone (castle wall slates), plaster, roof (grey tiles), redroof (clay tiles), wall (beige plaster), facade (concrete
  tile facade), sakura_bark, pine_bark. Groups that need more textures download them into their own folder.

## 3D models
GLB files, +Y up, front facing +Z, origin at the centre of the footprint on the ground, real size in metres.
A material named `tex:<name>` (for example `tex:stone`) is given the shared texture `world/tex/<name>_*` by the game,
tiled by the model's UVs, which must be in metres (1 UV unit = 1 m). A material named `window` is glass that lights up
at night. Any other material is used as exported.

## The `world` object (what runtime modules receive from the world engine)
```
world.size            16000
world.heightAt(x, z)  terrain height in metres (bilinear)
world.normalAt(x, z)  THREE.Vector3 (unit)
world.mapAt(x, z)     {road: metres to road edge, forest: 0..1, desert: 0..1, sakura: 0..1}
world.data            the parsed world.json
world.scene           THREE.Scene of the open world
world.camera          the active THREE.PerspectiveCamera
world.quality         0 low, 1 medium, 2 high (from the game's graphics setting)
world.tex(name)       {map, normalMap, roughnessMap?} from world/tex (cached, colour spaces set, RepeatWrapping)
```
A module should also work in a small test page that builds this object itself from `height.bin` and `map.png`.

## Performance budget (the game must run on school Chromebooks on Low)
- Whole open world: High under about 600 draw calls and 2 M triangles per frame; Low under about 250 and 600 k.
- Prefer instancing, merged geometry per material, LODs and impostors; texture size 1024 at most (512 on Low).
- Downloads: keep each GLB under about 2 MB (meshopt compression via `npx @gltf-transform/cli optimize ... --compress
  meshopt` is fine: the game has the meshopt decoder; Draco is not available).
